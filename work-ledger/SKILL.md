- "台账"、"工作台账"、"记录台账"、"四表台账"
- "生成台账"
- 描述本周/本阶段的工作内容并暗示需要生成四表台账

## 工作流程

### 第一步：收集信息

如果用户输入中缺少关键信息，**主动询问**（不编造）：

**必填项：**
- 本周每一天或各天做了什么（任务、产出）——表一表二是**整周逐天**的汇总

**可选项（有则填，无则跳过）：**
- 每天遇到的新问题/新发现/新知识——表二按天记录
- 风险或阻塞
- 任务看板信息（进行中/待办的任务）
- 每天工时

**已知固定信息（自动填充）：**
- 姓名：liuweiqing

### 第二步：一次性生成四张表

根据用户输入，同时生成四张表，**直接输出到对话中，不创建任何文件**。

**关键概念：这是一周汇总，不是单日记录。**
- **表一（每日工作记录）**：汇总本周每一天的工作，按天分行。如果用户输入没有明确区分每天，尽量按天拆分；无法区分则归到"本周"并标注日期范围。
- **表二（每日新增记录）**：汇总本周每天的新发现/新问题/新知识，按天分行。同表一逻辑。
- **表三（周报汇总）**：从表一表二提炼，一行总结整周。
- **表四（工具看板）**：从表一表二中进行中/需要跟进的事项提炼，跨天汇总。

四张表之间自动联动：
- 表一的进行中任务 → 表四自动生成对应看板条目
- 表二中"进看板=是"的事项 → 表四生成条目
- 表二中"进周报=是"的事项 → 表三归入
- 表三的一句话总结 → 从表一表二的核心产出提炼

如果用户输入不足以填充某张表，该表标注"暂无数据"并输出表头。

## 核心规则

1. **不创建文件，不存储数据**：四张表一次性生成并直接输出到对话中，供用户复制使用。
2. **不编造信息**：用户没提到的内容填"-"，空表标注"暂无数据"。
3. **四表联动**：表一表二的信息自动流转到表三表四，保持一致性。
4. **表格用管道符分隔**，不使用 Markdown 代码块包裹。
5. **日期统一格式**：YYYY-MM-DD；周次：YYYY-WXX。
6. **结论优先**：表三"一句话总结"先给结论再给证据。
7. **任务ID自增**：表四按 T-001, T-002 编号。
8. **导师列留空**：表一"导师备注"和表三"导师评价"始终留空。
