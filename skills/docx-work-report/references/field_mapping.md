# 字段映射与口语化输入指南

## 口语化输入到字段的映射

| 用户可能说 | 映射到 |
|-----------|--------|
| "XX任务完成了" | 状态=Done + 昨日完成 |
| "在做XX" / "XX进行中" | 状态=Doing + 今日计划 |
| "XX卡住了" / "被XX阻塞" | 状态=Blocked + 阻塞事项 |
| "导师说XX" | 导师反馈记录 |
| "需要XX协助" | 阻塞 + 需同步事项 |
| "这周效率很高/低" | 团队复盘 |
| "XX任务优先级最高" | 优先级=P0 |
| "干了X小时" | 工时 |
| "发现了XX问题" | 新增类型=问题 |
| "学到了XX" | 新增类型=知识 |
| "明天打算XX" | 明日计划 |
| "下周准备XX" | 下周计划/周报计划 |

## 状态值规范

| 状态 | 含义 | 使用场景 |
|------|------|---------|
| Backlog | 已知但未排期 | 任务看板/工具看板 |
| Todo | 已排期待开始 | 任务看板/工具看板 |
| Doing | 进行中 | 所有表 |
| Review | 待Review | 任务看板 |
| Done | 已完成 | 所有表 |
| Blocked | 被阻塞 | 所有表 |

## 优先级规范

| 优先级 | 含义 |
|--------|------|
| P0 | 必须完成，阻塞发布或核心功能 |
| P1 | 重要，计划内完成 |
| P2 | 有空再做，锦上添花 |

## 新增类型规范

| 类型 | 含义 | 示例 |
|------|------|------|
| 知识 | 新学到的方法/原理/配置 | bwrap /etc绑定机制 |
| 问题 | 新发现的bug/缺陷/风险 | 切换对话消息串话 |
| 机会 | 新的可能性/改进方向 | - |
| 资产 | 可复用的代码/脚本/文档 | WSL导出脚本 |
| 风险 | 潜在的负面影响 | Gemma4数值识别不准 |

## 严重程度规范

| 级别 | 含义 |
|------|------|
| S1 | 阻断流程，必须立即处理 |
| S2 | 功能异常，影响使用 |
| S3 | 体验不佳，可延后处理 |

## Agent模块分类

| 模块 | 涵盖 |
|------|------|
| Planner | 任务规划、多会话管理 |
| RAG | 检索增强生成 |
| Tool Use | 工具调用、skill集成 |
| Memory | 会话记忆、文件管理 |
| Eval | 评估、评价 |
| UI | 界面交互、消息折叠 |
| Infra | 基础设施、打包、沙盒、网络 |
| Other | 实验视频理解、SDK调研等 |

## 任务类型分类

| 类型 | 涵盖 |
|------|------|
| 开发 | 写代码、实现功能 |
| 实验 | 运行实验、验证假设 |
| 调研 | 查文档、调研方案 |
| 文档 | 写文档、更新注释 |
| 会议 | 开会、站会 |
| 调试 | 排查bug、定位问题 |
| Other | 其他 |

## 周次计算

Python 计算当前 ISO 周次：
```python
from datetime import date
d = date.today()
week_id = f"{d.year}-W{d.isocalendar()[1]:02d}"
```

周一为一周起始，周日为结束。
