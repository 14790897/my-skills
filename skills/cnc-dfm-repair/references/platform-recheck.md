# 平台复检与比价

用于本地 STEP 修复后的在线复检，或用户明确要求的加工降本。通过当次可用的浏览器工具及其文档操作；用户指定了浏览器和目标平台时沿用它们。技能本身不授予上传、提交订单或支付权限。

## 结果分层

报告时区分以下证据，不能互相替代：

1. 本地几何检查：有效实体、指定间距/材料厚度和保护区域比较。
2. 平台具体 DFM 项目及活动资格：记录实际文件名、提示原因及结果。“符合活动要求”不自动证明全模型每项 DFM 都无警告。
3. 平台编程、加工仿真与报价：读取实际总工时、分面工时、费用项和优惠资格。
4. 人工审核与订单状态：支付完成不能等同审核通过，预计交期不能等同已发货或到货日期。

截图编号只帮助定位，实际修改仍以对应 STEP 几何为准。若平台提示“存在LOGO”等活动分类问题，本地间距合格不能替代这项结果；浅浮雕可能改变分类，但不得从单个案例推断通用识别阈值。

## 页面状态判读

购物车行内的数字不能直接当结论，先分清三种状态：

- **通过**：继续走到「编程中 / 等待仿真 / 报价中」，最后出现费用项。
- **真实不通过**：几十秒内直接显示「不符合活动要求」并给出原因（存在窄槽 / 存在薄壁 / 存在LOGO）。
- **占位 / 降级**：同一行显示 `体积 = 包围盒体积`（80×80×5 → 32000）、`表面积 = "-"`。
  这是几何没解析出来时的兜底显示，**不要拿它当判定依据**。

口诀：**秒失败 = 真判定；进了「编程中」= 检测已通过**。要确认细节就点行内「查看DFM详情」——
弹窗里是真实数值（实测 21573.36 / 12069.83，与本地 STEP 完全一致），并逐项列出检测项目
（例如 24/25，只有「薄壁检测」标红）。列表页和详情弹窗给出的信息量差一个数量级。

平台高负载时页面顶部会挂「因当前下单量较大……已开启后台自动解析」，此时编程与报价可能排几十分钟。
判断「服务坏了还是模型坏了」的干净手段是**控制件**：拿一个已知能通过的文件改名重传。
但要注意，**已通过的文件再次加进购物车会命中缓存、瞬间出结果**，那不算一次实时解析。

## 费用项怎么读

一次报价里可能同时出现：基础费、材料拓展费、工时附加费。三者来源不同，不能混着看。

- **基础费**：「免费资格」命中时显示 ¥0，否则按特价档计（本项目观察到 ¥5）。
  免费名额按件占用——购物车里每多一个走免费资格的文件就吃掉一个。清空购物车后名额会回来。
- **材料拓展费**：尺寸/用料超出标准档时出现（本项目 4mm 版 ¥2、5mm 版 ¥3）。
- **工时附加费**：**这一项不出现，就说明加工时间已在免工时费门槛内**——这是判断能否做到 ¥0 的关键信号。
  本项目实测：双面 5mm → ¥5；双面 4mm → 无；单面 5mm → ¥2~3；单面 4mm → 无。

所以「做到免费」= ①拿到免费资格（基础费 0）**且** ②加工时间压在门槛内（无工时费）。
这两条相互独立，只看总价会误判原因。

## 风控

高频上传测试件、或多账号切换，会让页面出现「系统检测到异常参与行为，需实名认证后方可解锁活动权益」。
**此时连 DFM 检测都不跑**，行内只剩尺寸和占位数字。实名认证只能由用户本人完成；
不要反复重传试图绕过，也不要拿第二个账号「试试看」——活动规则明写多账号会永久取消免费权益
（本项目就因为一天内上传了十余版测试件、并登录过另一个账号而触发）。

先把候选文件和费用结构准备到位，等用户认证后再复检。

## 上传与等待

- 先核实文件绝对路径及版本，上传后核对页面文件名与预览。只使用用户授权的目标服务和文件范围。使用该浏览器文档规定的文件选择器流程。
- 上传完成、等待解析、等待编程、编程中、仿真中和最终报价是不同阶段。页面写“10–30 秒”或“3–5 分钟”是估计；本案例实际处理花了数十分钟。不要因超过提示时间就宣称模型失败。
- 进展未变时延长检查间隔，围绕状态变化更新用户，避免每几十秒重复完整页面或反复上传同一文件。确有必要刷新时，先确认已上传文件可在历史记录恢复，避免丢失用户草稿。
- 完成后的模型/刀路预览可能出现在新标签页。使用当前浏览器工具公开的标签页清单定位并核对文件名，不猜测链接或读取隐藏服务接口。
- 等待期间汇总栏的 `¥0.00` 可能只是尚未报价，不可宣称免费。需看到报价完成、费用项与对应活动结果。
- 若服务持续无进展且没有可执行的下一步，保留候选和当前页面，明确说明待平台处理及已完成范围。不要无上限地复制上传或改模型。得到明确结果后停止重查；未获授权不提交订单或付款。

## 可比较的降本结果

先看费用来源和分面/刀具工时，再选择与用户外观要求相容的候选。大量小刀加工或深浮雕可考虑减少深度；不要默认删字、缩小整体尺寸、改变日期或改成单面。已有明确外观偏好时直接沿用，缺少必要取舍才询问。

用相同材料、表面处理、数量和优惠资格比较。记录基础费、工时附加费、报价合计，以及运费或其他订单费用是否已包含。不得把划线原价当成实际应付价，或凭支付截图猜测额外费用。

降低铣除体积不代表等比例缩短工时；小刀精加工、进退刀和外形加工仍会耗时，阶梯报价也非线性。只按已完成的平台结果计算节省金额；活动限制与规则按当前页面核实，不把项目历史价格写成永久收费规则。

每个候选分别记录几何结果、活动结果和报价；被拒绝的候选标为不可用于该活动，不能与已通过版本混用。交付保留原版与明确标识的候选，给出外观取舍、实际工时/价格和截图证据。用户已经选定或支付的版本继续作为其选择，不擅自替换。
