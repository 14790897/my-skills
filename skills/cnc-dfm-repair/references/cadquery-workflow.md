# CadQuery/OCP 实施细节

## 诊断与选面

通过 `cq.importers.importStep(path).val()` 导入，检查 `isValid()`、`Solids()`、`BoundingBox()` 和 `Volume()`。确认 STEP 单位、导入单位与已知尺寸一致后再设 mm 阈值。辅助脚本报告的是导入坐标，不能独立证明单位。

水平面可按 `geomType() == 'PLANE'` 和 `abs(normalAt().z)` 筛选。Z、面积、包围盒、孔数共同作为指纹；导出再导入、布尔操作后，面顺序可能改变。浮雕字孔的底面也是水平面，筛选时核对高度与朝向，避免把孔底当成凸字。

`wire.sample(int)` 按点数采样，`wire.sample(float)` 的浮点数是偏差参数，**不是等距步长**。闭环绘图补回起点。采样及多边形化只用于可视化和候选筛查，分辨率必须足以识别被检查的小特征。OCP 的 `BRepExtrema_DistShapeShape` 可提供精确最近点；CadQuery 的 `a.distance(b)` 可复核真实 BRep 间距。

独立面的最近距离无法定位同一面内部的薄桥或窄槽。可以用轮廓局部法线、截面线与两侧边界交点分析；二维腐蚀后分裂是“存在细连接”的诊断线索，不直接等价于最小壁厚。平面倒圆、实体高度和局部材料厚度也不可混为一谈。

## 保持高度、原曲线和底面连接

水平浮雕可从原顶面构造目标实体：

```python
glyph = cq.Solid.extrudeLinear(face.outerWire(), face.innerWires(), cq.Vector(0, 0, dz))
```

`dz` 必须从实际顶面指向凹底，不能固定为 -2；检查得到的体积与包围盒。构造的实体只能代表该浮雕，不应覆盖同层圆盘。

缩小点画时可先围绕顶面中心缩放**平面**，再按原高度挤出：

```python
c = face.Center()
profile = face.translate(-c).scale(factor).translate(c)
new_glyph = cq.Solid.extrudeLinear(profile.outerWire(), profile.innerWires(), cq.Vector(0, 0, dz))
```

直接缩放三维实体会同时缩放 Z，可能使字悬空或改变凸字高度。变换后核对上下表面 Z。

弧排日期先识别真实圆心和每字原有方位。围绕同一 Z 轴旋转整个字符可保持同心排列及半径，不能用 X/Y 平移假装等角重排。文字“径向排列”和“切向沿弧排列”不同，沿用原文件的布局。

窄通道可由半径 `r` 的圆柱与宽 `2r` 的矩形棱柱并集合成胶囊形切削体；折线通道用相邻胶囊并集。切削体的起终点应进入已有空白，避免末端圆柱在笔画边上咬出无关凹坑。`2r` 只是刀具体宽，仍需检查成品通道全长及弯折处的真实最小间隙。

**但胶囊形切削体不能用来调笔画间距。** 那等于把笔画本体削掉，而且会在笔画上留下圆弧交线。
笔画之间的窄缝一律**整块平移笔画**（见 `cnc-part-design`）；上面这段只适用于确实需要挖掉材料的情形，
例如开孔、清理封闭区域，不适用于「两笔靠得太近」。

优先用原始边界、圆柱切削和局部圆角保留解析几何。`offset2D()` 对复杂 BSpline 可能返回空形状或失败；不要忽略异常。多边形近似可作为替代，但应标明容差、检查细碎边与光顺性，不能为了修改一个角重采样整个零件。

## 未修改区域比较

在修复前定义允许变化区域，例如修短尖尾的局部盒子、被移动字符的原位置与目标位置的包络。掩膜不要包含底板/外圈等需保护结构。比较对象应是有效实体，布尔比较异常不能当成“差异为零”。

`step_audit.py compare` 接受 JSON 数组，每个盒子为：

```text
[[xmin, ymin, zmin, xmax, ymax, zmax], ...]
```

实际 JSON 文件中的六项都必须是数值。盒子使用导入坐标，Z 范围覆盖目标浮雕层，不任意扩展到另一面。比较双方切除同一掩膜后的双向体积差，容差单位为坐标单位的立方。零差异只证明掩膜外一致，掩膜内仍需做字形、尺寸和保护项检查。比较还报告整体尺寸、有效性、实体数和文件哈希，不自动认定所有尺寸变化都不允许。

## 浅浮雕降本候选

适用于用户允许调整立体感的平底、直壁浮雕。另存候选，保留原始深度版本；先区分浮雕深度与整件厚度。例如本项目的 2 mm 指单面浮雕深度，整币厚度为 8 mm。

降低浮雕深度的一种做法是抬高已有凹槽底面，以补料减少待铣体积，保持凸字顶面与外圈原位：

```python
# floor_faces 已按实测高度、朝向、轮廓和预览核对；不能仅按面积选。
rise = old_depth - new_depth
pads = [cq.Solid.extrudeLinear(f.outerWire(), f.innerWires(),
        cq.Vector(0, 0, outward_sign * rise)) for f in floor_faces]
candidate = original.fuse(*pads).clean()
```

`outward_sign` 是该侧从底板朝外的 Z 方向，正反面分别处理。覆盖全部目标槽底，包括独立的字孔底面；保留各面内圈，避免填平文字或贯穿孔。不能用整片圆盘/矩形填层替代这些实际轮廓。带拔模、曲面底、圆角过渡的槽不能直接套用直壁挤出，需要按真实几何另行构造。

修改前将允许补料的范围定义为这些底面向外挤出的实体。导出后重导入并核对：

- 有效性、实体数、尺寸，以及新的槽底 Z 和实际浮雕深度。
- 原实体减去新实体的体积应为零；新增材料仅在预先定义的补料范围内，新增体积与目标几何一致。
- 新槽底以外的字顶、日期、圆盘外圈和挂孔保持一致；可对正反面外侧薄层及其他保护区域做双向布尔差异比较。
- XY 轮廓与关键间隙保留；平台仍须复检。几何有效不证明不会被平台识别为不支持的雕刻/LOGO 特征。

按模型尺度和 STEP 导入容差设置体积比较容差，并记录实测残差。本案例约 3,625 mm³ 的补料在 STEP 往返后的体积积分差约 0.0004 mm³；这类数值残差须和真实误删区分，不因断言失败就任意放宽容差。

## 交付边界

- 每次另存新文件，不能把旧版本链接当作新结果。
- 重新读导出的 STEP，检查实际输出而不只检查内存形状。
- 输出真实轮廓或实体预览，明确前/后与镜像规则。若只展示内圈，标为局部，不让用户误以为外圈丢失。
- 独立笔画间距通过、局部材料厚度通过、全模型 DFM 通过是不同结论，报告与实际验证范围一致。
