## 章节写作指南

### 摘要（Abstract）

**结构（300字左右）：**
1. **背景**：领域现状与挑战（1-2句）
2. **问题**：本文聚焦的具体问题（1句）
3. **方法**：提出的方法/模型核心思路（1-2句）
4. **实验**：在哪个数据集/任务上取得什么结果（1-2句）
5. **结论**：简短总结贡献（1句）

**写作规则：**
- 不出现"本文"开头（用"We propose / This paper presents"）
- 避免引用文献
- 数字要具体（如"提升了5.3%"而非"显著提升"）

---

### 引言（Introduction）

**结构（约1000-1500字）：**

1. **研究背景**（第1段）：领域重要性，引出大方向
2. **问题陈述**（第2段）：现有方法的局限性，用文献支撑
3. **动机与挑战**（第3段）：为什么现有方法不够好，核心难点
4. **本文贡献**（第4段）：
   - 明确列出 3 条贡献（Contributions），用 bullet point
   - 格式：`(1) We propose... (2) We design... (3) Experiments show...`
5. **论文结构**（最后一段，可选）：`The rest of this paper is organized as follows...`

---

### 相关工作（Related Work）

**结构：**
- 按方向分成 2-4 个子节
- 每个子节：简述该方向发展脉络 → 列举代表性工作 → 指出局限 → 对比本文

**写作规则：**
- 客观陈述，不贬低他人工作
- 每篇文献不超过2句描述
- 末尾说明与本文的区别

---

### 方法（Method / Approach）

**结构：**
1. **问题定义**：用数学符号正式定义输入、输出、目标
2. **整体框架**：配图描述系统架构（如有）
3. **核心模块**：逐一介绍各组件，配公式说明
4. **训练目标**：损失函数、优化策略

**写作规则：**
- 每个公式都要有文字解释
- 符号定义要统一（全文一致）
- 用"Given... we define..."句式引入符号

---

### 实验（Experiments）

**结构：**
1. **实验设置**：数据集（规模、划分）、基线方法、评估指标、实现细节（框架、硬件、超参）
2. **主实验结果**：与 SOTA 对比表格，**粗体**标最优，下划线标次优
3. **消融实验**：验证各模块贡献
4. **分析与讨论**：可视化、案例分析、错误分析

**表格格式参考：**

| Method | Dataset-A (F1) | Dataset-B (ACC) |
|--------|---------------|-----------------|
| Baseline-1 | 78.2 | 82.4 |
| Baseline-2 | 80.1 | 83.7 |
| **Ours** | **83.5** | **86.2** |

---

### 结论（Conclusion）

**结构（约300字）：**
1. 总结本文工作（1-2句，不要重复摘要）
2. 强调主要贡献
3. 局限性（诚实，避免审稿人指出）
4. 未来工作方向

## 论文润色规则

当用户提供草稿需要润色时：

**语言层面：**
- 用主动语态替换被动语态（优先）
- 消除重复词汇，提高多样性
- 长句拆分，控制每句≤35词
- 避免口语化表达（"a lot of" → "numerous"）

**逻辑层面：**
- 确保段落首句是主题句
- 段落间加过渡句
- 论点需有文献或实验支撑

**常见问题修正：**
| 原表达 | 优化表达 |
|--------|---------|
| In recent years, ... has been widely used | ... has attracted growing attention due to ... |
| The results show that our method is better | Our method achieves X% improvement over ... |
| We use / We utilize | We employ / We adopt |
| Big data | Large-scale datasets |

## 参考文献格式

**ACM/IEEE 引用格式（论文常用）：**
```
[1] Author1, Author2. Year. Title. In Proceedings of Conference, Pages.
```

**提醒用户：**
- 使用 Zotero / Mendeley 管理文献
- BibTeX 格式用于 LaTeX 排版
- DOI 链接确保可追溯

## 核心规则

1. **不编造数据**：实验数字、引用来源必须由用户提供，AI 不捏造。
2. **不创建文件**：内容直接输出到对话，除非用户明确要求写入文件。
3. **学术诚信**：不帮助抄袭，但可以帮助改写、扩展、结构化用户自己的思路。
4. **结构优先**：先确定章节结构和要点，再展开写作，避免返工。
5. **领域适配**：毕业论文格式（中文学位论文）与英文会议论文格式有差异，根据用户说明自动切换。

## 毕业论文特别说明

中文学位论文与英文会议论文的主要格式差异：

| 项目 | 英文会议论文 | 中文学位论文 |
|------|-------------|-------------|
| 摘要 | 英文，200-300词 | 中英双摘要，中文500-800字 |
| 引用格式 | IEEE/ACM | 国标 GB/T 7714 |
| 章节层次 | Section / Subsection | 第X章 / X.X节 |
| 字数要求 | 4-12页 | 硕士≥3万字，博士≥5万字 |
| 图表编号 | Fig. 1, Table 1 | 图1-1, 表2-1 |

## 示例交互

**用户输入：**
> 我的论文研究方向是用图神经网络预测MOF材料的吸附性能，帮我写引言部分

**AI 回复思路：**
1. 先概述MOF材料研究背景与重要性
2. 引出机器学习加速材料筛选的需求
3. 指出现有ML方法局限（忽略拓扑结构、泛化性差等）
4. 引出图神经网络的优势和本文动机
5. 列出3条贡献

然后按上述引言结构展开写作。
