# 火影忍者手游 · ADB 每日任务

2026-11-15 实测（账号 127 级 V6，服务端在**腾讯 START 云游戏**里）。

## 一、环境与坐标口径

- 游戏跑在 `com.tencent.start/.ui.PlayActivity`，是**云游戏串流**。
  点击会转发到云端实例，每次操作后要留 1.5~3 秒等画面刷新。
- 手机是竖屏 1080x2400，但游戏横屏运行，**截图与 `input tap` 共用 2400x1080 的坐标系**。
  换算：截图里显示的坐标 × 1.2（若显示尺寸是 2000x900）就是 adb 坐标。
- Git bash 会把 `/sdcard/...` 当 Windows 路径改写，**每条 adb 命令前都要
  `export MSYS_NO_PATHCONV=1`**，否则报 `C:/Program: No such file or directory`。
- adb 服务端会在长时间运行中自己挂掉。报 `cannot connect to daemon` 时：
  `adb kill-server && adb start-server`，几秒后设备会重新出现。

```bash
export MSYS_NO_PATHCONV=1
adb shell screencap -p /sdcard/_nl.png && adb pull /sdcard/_nl.png shot.png && adb shell rm /sdcard/_nl.png
```

现成脚本见 `scripts/shot.sh`。

## 二、三个必须记住的坑

### 1. 左上角那个蓝色箭头不是「返回」

画面左上 (186,144) 附近有个蓝底小箭头，**每一屏都有**——那是
**START 客户端**的侧边菜单，点开是「通用设置 / 帮助反馈 / 重启游戏 / 退出游戏」。
游戏自己的返回是：

- 各面板**右上角的橙色 X** ≈ `(2280, 46)`
- 面板**左下角的「返回」** ≈ `(126, 954)`

### 2. BACK 键行为不一致

| 场景 | BACK 效果 |
|---|---|
| 剧情关卡 / 过场动画 | ✅ 正常退出战斗 |
| 招募、多数功能面板 | ❌ 无反应（要找 X） |
| START 设置抽屉打开时 | ✅ 关掉抽屉 |

**不要拿 BACK 当通用返回**，在面板里会白等。

### 3. 剧情关不能拿来刷次数

冒险副本里的关卡若带「**剧**」角标，是剧情限定关，进去先播过场，只能「跳过」不能扫荡，
刷 10 次会疯。刷次数必须找**三星普通关**（详情页右下角有「扫荡」）。

## 四、每日任务面板（奖励 → 每日任务）

`奖励 (2314,540)` 打开，左侧三个页签：**每日任务 / 奖励中心 / 日历**。

### 4.1 列表会轮换，不是固定 5 项

横排 5 张卡，**不可横向滑动**（试过，没反应）。完成某项后它从排里消失、
后面的任务滑进来。所以做完一项要**重新截图再点**，别沿用旧序号。

五张卡的「立刻前往」按钮 y 都是 **654**，x 依次：

```
card1 (474,654)  card2 (852,654)  card3 (1236,654)  card4 (1620,654)  card5 (1986,654)
```

### 4.2 活跃度是「按次递增」给分

例：金币招财 5 次 = 总共 +10，做 1 次就记 +2。
所以**部分完成也有分**，不用非得做满。

### 4.3 档位与已见任务

宝箱档位 **10 / 40 / 80 / 100**，日活跃上限 500（周）。宝箱坐标
`(1030,840) / (1344,840) / (1812,840) / (2022,840)`（后三个为估计）。

| 任务 | 次数 | 活跃度 | 真实成本 |
|---|---|---|---|
| 冒险副本挑战 | 0/10 | +20（每次 +2） | 体力 5/次 |
| 组织祈福 | 0/1 | +10 | 6000 铜币 |
| 进行1次金币招财 | 0/5 | +10（每次 +2） | 有免费次数，其余耗券 |
| 忍者招募 | 0/1 | +10 | 券 |

## 五、各任务怎么做

### 一乐外卖（免费体力，最优先）

`活动 (2254,56)` → 左栏「一乐外卖」。3 个箱子各 +50 体力：

```
(648,426)  (1128,426)  (1518,420)
```

点完箱子变成「售罄」牌，底部提示「拉面都领完了，明天记得再来！」即全部领完。
中途可能弹「高画质体验」横幅，X 在 `(1824,118)`。

### 组织祈福

`剩余次数` 显示当天可做几次（通常 1）。三档：

- **焚香祈福 `(1034,840)` — 6000 铜币，3 密令** ← 用这个，别用券
- 纳贡祈福 `(1440,840)` — 120 券
- 虔诚祈福 — 240 券，V9 才开

### 金币招财

「第1/2轮，累积投币 0/10」。**免费一次 `(1494,840)`** 先点；
「招完本轮」`(1848,840)` 是 **130 券**，不要碰。
免费次数用完后按钮区变成「扫荡10次」勾选框 `(1332,702)` + 继续 `(1548,702)`。

### 冒险副本（刷 10 次最快路径）

`冒险 (2178,978)` → 顶部页签保持「冒险副本」→ 点章节卷轴 → 选**三星普通关**（别选带「剧」的）。

详情页右下 **扫荡 `(1992,936)`** → 弹窗出现「**扫荡10次**」勾选框 `(1332,702)`
+ 开始扫荡 `(1548,702)`。

- 第一次点只扫 1 次；**勾上 10 次再点**才一次扫完。
- **扫荡不消耗扫荡券**，只花体力（每次 5）。实测 10 次体力 1050→995。

### 高级招募

`招募 (2316,288)` → 左栏「高级招募」。

- **免费 `(1788,840)`**：每日 1 次，免费抽
- 招募1次 `(1206,822)` — 1 张招募券
- 招募10次 `(1584,822)` — 10 张
- 结果页「确定」`(840,822)`

⚠️ **付费抽首次会弹「您尚未设置二级密码保护」**，只有「前往设置」一个按钮。
点空白处 `(480,480)` 关掉，**这次抽不会生效**，必须再点一次招募按钮。
绝对不要替用户去设二级密码。

### 任务集会所（唯一跨天/跨小时的项）

`任务集会所` 里是真实时间派遣：12h / 6h / 3h。流程：

1. 行右侧「领取」`(2016, 452 / 619 / 786)`
2. 忍者选择页点 **推荐小队 `(1650,840)`** 自动填好羁绊双人
3. **出发 `(2052,930)`**

⚠️ **「接受」不算完成**。每日任务 `完成集会所任务 0/3` 只认**派遣倒计时结束**。
所以这项**当天无法即时做完**，接完等几小时回来领。说完这事要跟用户讲清楚。

## 六、决斗场连点 —— 本次最大的一课

### 6.1 入口

`决斗场 (882,456)` → 底部「**忍术对战** `(672,918)`」→ 右下「开战 `(2256,924)`」。
`决斗任务` 面板底部写明：**决斗任务仅在忍术对战和段位赛中完成**。
一场比赛每 KO 一个忍者算一「回」，会打到第 4、5 回，是把对手 3 个忍者全打完。

**结算只认整场胜利**：输了的场次，`今日首胜 0/1`、`击败1名忍者 0/1`、`本周胜场` 都不动。

### 6.2 关键：按钮位置随忍者变化

不同忍者的技能按钮**数量和位置都不一样**。用一套固定坐标会大量点空——
本次就因为这件事被用户说「技能没按出来」「你太笨了」。

**正确做法是每次进战斗后先量一次**：

```bash
python scripts/crop_controls.py shot.png controls.png
```

它会裁右侧 1/3 并 2 倍放大，并打印 `屏幕坐标 = (x0 + 裁剪图x/2, 裁剪图y/2)` 的换算式。
照着放大图读出：**普攻、各技能、替身** 的圆心，再开始连点。

参考（神秘面具男，某一局实测）：普攻 `(2126,875)`、技能 `(2137,236) (2129,410) (2137,615)`、
蓝卷轴 `(1929,721)`、橙技能 `(1905,942)`、**替身 `(1705,942)`**。**这只是那一局的，别照抄。**

### 6.3 连点必须在设备内循环

host 端每条 `adb shell input tap` 一个进程往返，实测只有 **~6 次/秒**，完全不够。
把 while 循环塞进设备 shell，实测 **150 次点击 6.4 秒 ≈ 20 次/秒**，是能赢和不能赢的分界线。

```bash
# scripts/tap_loop.sh 的实质
adb shell 'i=0; while [ $i -lt 400 ]; do
  input tap 2126 875; input tap 2137 236; input tap 2129 410; input tap 2137 615;
  input tap 1929 721; input tap 1905 942; input tap 1705 942; input tap 2126 875;
  input tap 2126 875; input swipe 420 840 350 840 70;
i=$((i+1)); done'
```

要点：

- **普攻多打几次**，技能夹在中间；命中率比花样重要
- 结尾夹一次**小幅左滑 `(420,840)→(350,840)`** 当位移，靠近对手
- 循环放后台跑（`run_in_background`），每隔 20~30 秒截图确认战况和是否换了忍者
- **换忍者后要重量坐标**，否则后半场又开始点空
- 战斗区之外的坐标（比如 `(2178,930)`）在别的界面可能误触按钮，回主城后先停循环

### 6.4 已知提示语

- 「技能正在冷却中」= 技能在 CD，正常，继续点
- 「通灵兽技可使用次数不足」= 通灵次数用完了

## 八、排错

| 现象 | 处理 |
|---|---|
| `与服务器断开连接，正在重连中` | 等 8~15 秒，云游戏自己会连回来 |
| adb 里设备消失 | `adb kill-server && adb start-server`，等 5 秒 |
| 点屏幕没反应 | 大概是点到了 START 客户端的浮层；换面板自己的 X |
| 画面全黑 | 正在转场 / 加载，等 5~10 秒再截 |
| 扫荡只扫了 1 次 | 勾「扫荡10次」再点继续 |
| 付费抽弹二级密码提示 | 点空白处关掉，再点一次抽；**不要设置密码** |

## 九、一次完整的日常顺序

1. 活动 → 一乐外卖：3 个免费体力
2. 奖励 → 每日任务：截图看今天有哪 5 项
3. 组织祈福（铜币档）
4. 金币招财（只用免费次数，除非用户同意花券）
5. 冒险副本 → 三星普通关 → 扫荡 10 次（耗 50 体力）
6. 高级招募（免费那次）
7. 任务集会所：接 3 个派遣（短的优先），跟用户说明要等几小时
8. 决斗场：进战斗 → **先量按钮** → 设备内连点 → 每 20~30 秒看一次
9. 回每日任务面板，领 10/40/80/100 活跃度宝箱

## 十、给用户的沟通要点

- 云游戏是串流的，我盲操作 PvP 胜率不保证，**开打前问一句要不要打**
- 集会所当天做不完要说清楚，别说「做完了」
- 花了券、体力、铜币要报账
- 用户要「连点」时就是字面意思：**别停、别自作聪明去分析，一直点**
