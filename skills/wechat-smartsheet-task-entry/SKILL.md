# 腾讯智能表任务录入（只做插入）

## 适用范围

- 文档：默认地址 `https://doc.weixin.qq.com/smartsheet/s3_AUMArQZHAFoCN4y0kQj1fTa22MvxQ`
  （「任务进度与需求统计表」智能表）；用户另行指定文档地址时以指定为准。
  主表 tab id（形如 `<tabId>`）为内部信息，使用时按实际环境现查。
- 主表：**主表**（内部表名略；tab id 形如 `<tabId>`）——任务只加在这里，
  用户明确要求「只进主表」。
- 其他工作表：仪表盘表（只读统计）、分析报告表。**不要新建工作表。**
- 本技能**只做新增插入**：把新任务追加到表尾、填字段、设状态、复核。
  不修改历史记录、不删除行、不调整行序。
- 负责人列显示为「研发」，默认填**本人**（表里用真实姓名，注意别写错字）。
- 工具：`browsermcp` 操作已登录的用户 Chrome（不要用 headless / preview 浏览器）。

## 必填输入（每次插入前确认）

插入一条任务以这四项为必填输入，请求里已给出就直接用，缺哪项先问用户：

| 输入 | 对应抽屉字段 | 填法 |
|---|---|---|
| 文档地址 | — | 默认 `https://doc.weixin.qq.com/smartsheet/s3_AUMArQZHAFoCN4y0kQj1fTa22MvxQ`，用户另行指定则用指定地址 |
| 研发人员 | 研发（成员） | 点成员选择器，搜真实姓名选中；未指定时默认本人 |
| 需求提出方 | 需求提出方（文本） | `.text-editor`，直接输入 |
| 截止日期 | **计划上线时间**（日期） | 日期 input，输入后按 Escape / 点其它标签关闭选择器 |

任务描述（要做什么）来自请求文本，与这三项一起构成一条完整记录。

## 硬规则（先记住再动手）

1. **新增任务必须插入到表格最后一行之后**。
   - 正确入口：滚到表的最底部 → 选中**当前最后一条记录**的行号 → 行右键菜单 →「向下插入」，
     新空行会出现在表尾。
   - **不要用「添加一行」**：它总是插在当前活动行**上方**（活动行在第 1 行时会顶到表头），
     不会追加到末尾。
   - 不要在中间行用「向上插入 / 向下插入」造行。
2. 表格是 **canvas 渲染**：文字不在 DOM 里，只能截图看或经「记录抽屉」读；
   不要指望 `innerText` 或 ARIA 拿行数据。
3. **行号是视图序号**：「进度状态」视图按状态分组，改状态或切视图会让行号重排。
   插行前必须滚到最底部、以屏幕上可见的最后一条记录为准，别用旧截图里的行号/坐标。
4. 工作表切换：侧栏项是 DOM，`document.querySelector('#sheet-component-<tabId>').click()` 可切表；
   tab id 用 `Array.from(document.querySelectorAll('[id^="sheet-component-"]')).map(e => [e.id, e.innerText])` 现查。
5. **行菜单判断**：在行号区右键 → 菜单含「展开记录 / 添加子记录 / 创建副本 / 向上插入 / 向下插入 / 删除」。
   **有「展开记录」才是行菜单**；侧栏工作表右键是另一套。
6. **记录抽屉**（行菜单→展开记录）：右侧打开 DOM 表单，标题 = 任务描述值，可读可改：
   项目名称/所属模块、任务类别、任务描述、研发（成员）、状态、优先级、任务提出时间、计划上线时间等。
   全部改动**自动保存**。
7. **状态是单选**：点抽屉里的「状态」combobox（browsermcp 真实 click 有效；合成的 mousedown
   序列对部分控件无效）→ 弹出选项：完成 / 需求提出 / 策划中 / 测试中 / 开发中 / 验收中 / 关闭 → 点目标项。
8. **复制/粘贴整行**：选中源行行号 `Control+c`，到目标行行号 `Control+v`。
   粘贴**覆盖所选行**（不是插入），且**不携带「状态」列**——粘完必须单独补状态。
   - 行号在 canvas 上，**x 随水平滚动变化**；右键试开菜单：出现「展开记录」才说明命中行号。
   - 截图是缩略图，**坐标每次都不同，永远用「展开记录」抽屉标题核对目标行，不要盲信坐标**。

### 抽屉字段定位与选项

- 用 eval 给右侧可见的 `[role=combobox],[role=listbox]` 按 y 排序赋临时 id；顺序：
  项目名称/所属模块(0)、任务类别(1)、状态(2)、优先级(3)、涉及端(4)、需求来源(5)。
- `.text-editor` 按 y：任务描述、需求提出方、备注；日期 input：
  任务提出时间、计划上线时间、研发开始时间（+ HH:mm）。
- **「剩余时间」是公式字段**（如「1 个工作日前已截止」），没有手填的「完成时间」；
  表达「完成日今天」= 状态设为「完成」+ 计划上线时间设为今天。
- 常用选项（**具体取值按实际表格**，这里只列形态）：
  - 项目：多个内部项目名，多选（可同时挂两个，如「项目A + 项目B」）
  - 类别：宣传 / 调研 / 测试 / 产品 / 开发
  - 状态：完成 / 需求提出 / 策划中 / 测试中 / 开发中 / 验收中 / 关闭
  - 优先级：P2 / P0 / P1
  - 涉及端：MAC / WIN
  - 需求来源：需求对接 / 定期组会 / 老板要求 / 实验室 / 运营中心 等（内部来源名，按实际取值）

## 标准流程：新增 N 条任务（逐条插到表尾）

1. 打开文档地址（默认 `https://doc.weixin.qq.com/smartsheet/s3_AUMArQZHAFoCN4y0kQj1fTa22MvxQ`，用户指定了别的就用指定的）；切到主表 tab；滚到最底部，确认屏幕上最后一条有内容的记录。
2. 找一行同结构的历史任务作模板：行号右键 → 展开记录，确认内容结构后关闭。
3. 对每条新任务：
   a. 选中**当前最后一行**的行号 → 右键 →「向下插入」→ 表尾出现新空行；
   b. （可选，推荐）选中模板行行号 `Control+c` → 选中新空行行号 `Control+v`，粘贴覆盖该空行；
   c. 展开新行记录：填 任务描述、**需求提出方**、项目名称/所属模块、任务类别、优先级、任务提出时间、**计划上线时间 = 截止日期**；
   d. **研发人员**：点研发字段，在成员搜索里选真实姓名（未指定时默认本人）；
   e. **补状态**（粘贴不携带状态列）→ 按需选「开发中」等；
   f. **用抽屉标题核对**：标题应等于新任务描述，改完再关；
   g. 做下一条前，重新选中此刻的最后一行（刚完成的那条）→「向下插入」，重复。
4. 全部插入完成后逐条复核（见下）。

## 复核（必做）

- 重新展开每条新记录的抽屉读字段值；或**刷新页面后再读**。
- 保存偶发静默失败（控制台大量 503 时尤其危险）——**UI 里的“已显示完成”不等于服务器已保存**；
  曾出现 3 条状态丢失。
- 仪表盘表的统计（任务总数/已完成数）是服务器数据的旁证。

## 已知坑（与插入相关）

- **「添加一行」总是插在当前活动行上方**（活动行在第 1 行时会顶到最顶部），不要用它来“加到底部”。
- **键盘滚动不可靠**：搜索框/抽屉有焦点时 `Control+End`、`ArrowDown` 不会移动画布；
  用 `WheelEvent(deltaY)` 派发到 canvas 滚动，向上用负值。
- **日期输入会弹日期选择器**，覆盖下面一行；输入后按 Escape 或点其它标签关闭，
  再操作下一个控件，否则会报 “#tmp-input-x is covered by div”。
- 粘贴覆盖的是“当前选中行”，选错一行就覆盖了别的任务；粘贴后必须逐条核对。
- 空白行是显示占位：选中空行粘贴即可写入；不要用插入菜单在中间造行。
- 底部行附近坐标容易差一行：右键后先看「展开记录」打开的标题再决定是否操作。
- 数字/日期列粘贴为文本时格式可能不一致，优先在抽屉里改。
- 「导入表格」会新建工作表，不会追加到主表；「追加导入数据」入口经常不可用。用户拒绝这种做法，别用。

## 交付时的说法

- 报告里写清：加了哪几条（任务描述、研发人员、需求提出方、截止日期、类别、优先级），以及**复核结果**（服务器侧读到的一致状态）。
- 有失败/未保存的，如实说明并补做，不要按“应该已保存”上报。
